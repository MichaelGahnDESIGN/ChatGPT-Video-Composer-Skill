# Erste Schritte

## Voraussetzungen prüfen

Im Repository ausführen:

```bash
./scripts/pruefe-video-umgebung.sh
npx hyperframes@latest --version
```

Die Prüfung ist rein lesend. Fehlendes Higgsfield verhindert keine lokale Produktion.

## Video-Projekt anlegen

Beginne mit zwei klaren Dokumenten:

- `BRIEF.md`: Zielgruppe, Botschaft, Format, Länge und vorhandene Quellen.
- `STORYBOARD.md`: zeitcodierte Szenen, Medienquelle, Text, Ton und Freigabestatus.

Bewahre Originale unter `assets/original/` auf und bearbeite ausschließlich Kopien.
